# BaruJak - Unearthing Jakarta's Risk-Scape: A Participatory, Data-Driven Platform for an inclusive and Resillient Jakarta

## Welcome to BaruJak

[BaruJak](https://www.barujak.org/) is a participatory, data-driven platform for building an inclusive and resilient Jakarta. This comprehensive guide will help you navigate and use all features of the platform effectively.

BaruJak creates meaningful connections between diverse stakeholders in Jakarta's resilience ecosystem. By bridging the gaps between communities, policymakers, researchers, NGOs, and the private sector, we enable collaborative solutions that combine local knowledge with institutional resources and expertise.

## Getting Started

### First Time Visit
1. **Visit the Homepage**: Navigate to the BaruJak platform
2. **Language Selection**: Use the language switcher in the top right to choose between English (EN) and Indonesian (ID)
3. **Explore Without Account**: Browse the Risk Index and Kampung Profiles without creating an account
4. **Sign Up to Participate**: Click "Sign In" or "Join Our Mission" to create an account for full access

### System Requirements
- Modern web browser (Chrome, Firefox, Safari, Edge)
- Internet connection
- JavaScript enabled
- Responsive design works on desktop, tablet, and mobile devices

## Platform Overview

### Mission
BaruJak bridges the data gap between official urban planning data and community lived experiences. The platform combines quantitative data (Social Vulnerability Index, environmental hazard maps) with qualitative community stories to create a comprehensive picture of Jakarta's risks and resilience.

### Core Principle
"From sinking land to rising voices" - Making risk visible and actionable for all stakeholders.

## Page-by-Page Guide

### 1. Homepage (/)

**Purpose**: Main entry point showcasing platform mission and key features

**Key Sections**:

- Use navigation menu for other sections

### 2. Risk Index (/risk-index)

**Purpose**: Interactive dashboard for exploring Jakarta's risk and vulnerability data

**Main Components**:

#### Map Interface
- **Interactive Map**: Color-coded kampungs based on risk levels
- **Hover Effects**: Quick risk scores on mouse hover
- **Click to Explore**: Detailed information panels
- **Zoom and Pan**: Full map navigation controls

#### Filter Controls
- **Composite Index** (default): Overall combined risk score
- **Sensitivity**: Social and demographic vulnerabilities
- **Adaptive Capacity**: Community resilience factors
- **Exposure**: Environmental and physical risks

#### Search Functionality
- **Search Bar**: "Search for a kampung..."
- **Auto-complete**: Suggestions as you type
- **Direct Navigation**: Click results to zoom to location

#### Data Visualization
- **Technical Charts**: Detailed vulnerability analysis
- **Risk Scores**: Numerical ratings and categories
- **Trend Analysis**: Historical risk patterns

**How to Use**:
1. Select a filter category from the control panel
2. Use search bar to find specific kampungs
3. Click on map areas for detailed information
4. Use the information panel to explore data
5. Click "View Full Profile" for complete kampung details

### 3. Kampung Profiles (/kampung-profiles)

**Purpose**: Browse and access detailed community profiles

**Features**:
- **Profile Grid**: All available kampung profiles
- **Quick Preview**: Basic information and risk scores
- **Direct Access**: Click to view full profiles

**Individual Kampung Pages**:
- **Profile Header**: Name, banner image, key statistics
- **Risk Dashboard**: Detailed vulnerability breakdowns
- **People's Voice**: Community stories and photos
- **Data Visualizations**: Charts and graphs specific to the kampung
- **Location Information**: Geographic and administrative details

**Available Kampung Profiles**:
- Kampung Akuarium (/kampung-profile/kampung-akuarium)
- Kampung Muara Angke (/kampung-profile/kampung-muara-angke)
- Kampung Marlina (/kampung-profile/kampung-marlina)

## Troubleshooting

### Common Issues

#### Map Not Loading
- **Check Internet Connection**: Ensure stable connectivity
- **Browser Compatibility**: Use updated browser
- **JavaScript**: Verify JavaScript is enabled
- **Refresh Page**: Try reloading the page

#### Search Not Working
- **Check Spelling**: Verify kampung names
- **Try Partial Names**: Use partial search terms
- **Clear Search**: Reset and try again

#### Account Issues
- **Forgot Password**: Use password reset link
- **Login Problems**: Check credentials and try again
- **Profile Issues**: Contact support through help page

#### Chatbot Not Responding
- **Internet Connection**: Check network status
- **Refresh Chat**: Close and reopen chat interface
- **Browser Cache**: Clear browser cache if needed

### Getting Help
- **FAQ Page**: Visit /help for common questions
- **Contact Support**: Use /contact for direct assistance
- **Community Forums**: Engage with other users
- **AI Assistant**: Ask the chatbot for immediate help

## Support and Feedback

### About Us
Barunah is an interdisciplinary collective of five urban practitioners with backgrounds in architecture, data analytics, mobility research, heritage studies, and community-based planning. Together, we bridge quantitative modelling and field-based research—moving between zoning maps, kampung alleys, policy documents, and household stories. Our experience ranges from analysing risk indices and satellite imagery to working directly with kampung cooperatives and documenting Jakarta’s historic water systems.

Through BaruJak, we aim to build an open, participatory data platform that not only visualizes risk, but helps connect city officials and kampung residents in shaping just, inclusive, and resilient futures for Jakarta.
